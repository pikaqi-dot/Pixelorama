# LAN Sync

把构建出来的应用和装了本插件的 Godot 编辑器连在一起，在局域网内**按需同步指定文件夹**。
两侧靠 UDP 广播自动发现、自动连接，不需要输入 IP；网络屏蔽广播时可以在界面里手填地址。

**同步是拉取式的，而且是手动的**：连接建立后什么都不会自己动；在哪一侧点「同步一次」，就把**对方**文件夹里的内容拉过来，**覆盖**本机同名文件。想双向就把两边各点一次。

## 它做什么

- **自动发现**：每秒一次 UDP 广播（端口 `45999`），同网段的另一侧会出现在「附近设备」里。广播同时发给 `255.255.255.255` 和**每个网卡自己网段的广播地址**（如 `10.52.20.255`）——机器上装了 Hyper-V、WSL、VPN 时，有限的广播地址常常只从「路由表更喜欢的」那块网卡出去，而那块往往不是 Wi-Fi。
- **主动扫描**：点「扫描局域网」同时做两件事，扫本机所在网段的 254 个地址。
  - **UDP 探测包**（端口 `45999`）：被扫到的设备只回一个单播包并带回它的 TCP 端口，不建立任何连接，不留 TIME_WAIT。
  - **TCP 直连**（端口 `45990`）：直接拨同步端口，连上的那条连接**就是**会话本身，不再重拨。这一步是关键——对方是 Windows 且防火墙拦了入站时，它的广播和探测回复都会被丢掉，但**它的出站是通的**，所以「我去拨它」是唯一还能发现它的方向。
  - 只扫最可能的 4 个网段，本机自己的地址跳过（否则会配对自己）。
- **自动连接**：发现后由 id 较小的一侧发起 TCP（端口从 `45990` 起，占用则顺延），只建立一条连接。
- **必须对方同意**：连上之后发起方 **不会** 读取或写入任何东西，而是等接收方弹出「同意 / 拒绝」。接收方点同意才开始交换清单；点拒绝或 30 秒不答就断开。扫描只能发现设备，不能替人做决定。
- **拉取式同步**：点「同步一次」的一侧发出 `pull`，对方回它的清单，然后逐个文件索取。**方向由按钮决定**：谁点，谁拉。远端优先，本机同名文件被覆盖；内容已经相同（哈希一致）的跳过，不做无谓写盘。
- **完全手动**：连接建立后不发起任何交换，不会每几秒自动同步一次，也不会因为你切回前台就自动拉取。连接只是个通道，什么时候用由人决定。
- **按了就有回音，而且说清原因**。点完会得到类似：`拉取完成：收到 1 个，跳过 2 个（本机 1 个文件，对方 3 个）`，被跳过的会分开写原因：
  - `1 个文件所属的文件夹没有在本机共享，已跳过` —— 对方有这个文件夹名的文件，你这边没有配同名文件夹。
  - `1 个文件内容已经相同，已跳过` —— 哈希一致，不重写。
  - 某个文件夹一个文件都没列出来时，会直接说为什么：`shared：读不到这个目录 …` / `shared：目录里没有可同步的文件（…）` / `shared：还没有设置路径`。
  这样"明明有文件却显示 0"就不会再无解——日志会指出是本机读不到、还是哪一侧没共享同名文件夹、还是内容真的一样。文件夹列表里也会显示每个文件夹现在有几个文件。
- **不做无用功**：哈希按「时间戳 + 大小」缓存（10 秒兜底过期），没变过的文件不重读；清单哈希是边读边算的。
- **卡住的拉取会自己收尾**：超过 15 秒没收到对方的任何字节，就放弃这一次（连接保留），否则它会永远停在 "传输中"，按钮再也点不动。
- **切走再回来不掉线**：手机打开文件选择器或切到后台时应用会被暂停，主循环停了但时钟没停。恢复时所有超时时间按离开的时长顺延，否则连接会被判成超时、待确认的请求会自己消失。
- **断线自动重连**：如果连接在挂起期间被系统断掉，**按最后成功的地址自动重连**：1 秒后开始，之后每 3 秒一次，直到对方应答，不用再手动点。
- **只覆盖，不删除**：任何一侧删文件都不会同步过去，避免误删。
- **文件夹按名字配对**：两侧各自设置路径，只有名字相同的文件夹才会互相同步。

## 编辑器侧

插件默认启用。打开右侧 `LAN Sync` 停靠面板：

1. 默认已有一个名为 `shared` 的文件夹，路径是项目里的 `res://lan_shared`（首次运行自动创建）。
2. 点「开始」。
3. 同一局域网里运行的应用，进入「同步」页签后点「开始」，双方应在几秒内互相出现。
4. 在任意一侧点「同步一次」，就是把**对方**的文件拉过来；这边拉了之后编辑器会自动重扫描资源，新图片会正常导入。

要同步别的文件夹：点「浏览」选目录，再点「添加」就够了——

- 「名称」留空时取目录自身的名字（`…/MyArt` → `MyArt`），两侧靠这个名字配对，所以**名字必须和应用侧一致**。
- 路径留空时用默认目录：编辑器 `res://lan_shared/<名称>`，应用在 Android 上是 `下载/Pixelorama/<名称>`、其它平台是 `user://lan_shared/<名称>`。
- 两栏都空着点「添加」只会提示，不会加进任何一条。

## 应用侧

主界面顶部页签里的「同步」：

1. 默认同样有一个 `shared` 文件夹。**在 Android 上它落在系统下载目录**：`下载/Pixelorama/shared`，文件管理器、相册都能直接看到；桌面端仍然是 `user://lan_shared/<名称>`。
2. 点「开始」。
3. 等对方出现在「附近设备」。之后点「同步一次」把对方的文件拉到手机（覆盖同名文件）；想让电脑拿到手机上的图，就在**电脑那一侧**点同一个按钮。

关于 Android 的下载目录：

- 能不能写是**实测**出来的，不是看着路径对就当能写：启动时先试着建目录并丢一个探针文件，写不进去就退回应用自己的目录，日志里会写清楚落在哪。
- Android 11 起，直接往 `Download` 写需要「所有文件访问权限」。导出预设已经声明了 `MANAGE_EXTERNAL_STORAGE`，如果日志说退回了私有目录，就去 **设置 → 应用 → Pixelorama → 特殊权限 → 所有文件访问权限** 打开它，再重开同步页。
- 旧版本装在手机上的 `shared` 还留在应用私有目录里，更新后会**自动搬一次**（连同文件一起，不覆盖已有文件），日志会打印 `shared 已移到 …`。
- 已经在用的其它文件夹，可以在列表里选中后点 **「移到下载目录」**，不用手打路径。

## 手填地址

两侧面板上都有「本机地址（填到对方）」一行，**点「开始」之前就在**（此时只有地址、没有端口，因为还没开始监听），点开始后补上 `:45990` 这样的端口。点「复制」就能把这一串原样填到对方的「按地址连接」里。

- 网卡多的机器（Hyper-V、WSL、ZeroTier、Tailscale）会有一堆地址。这一行给的是网卡名像 `WLAN`、`以太网`、`wlan0` 的那一条；其余地址收在鼠标悬停提示里，日志里也会打印 `本机网卡：WLAN 10.52.20.82 …`。
- 手机上「本机地址」在 Wi-Fi 重新连接后会自动刷新（每 2 秒一次），不用退出页面。

## Windows 防火墙

**最省事的做法**：双击项目里的 `tools\fix-lan-sync-firewall.bat`。它会申请管理员权限、删掉 Windows 给编辑器进程建的那几条入站**阻止**规则，再放行 `TCP 45990-45997` 与 `UDP 45999`（所有配置文件）。

为什么要先删：Windows 弹「是否允许访问」时点过取消，系统就会给那个 exe 建一条入站 **Block** 规则；**Block 规则优先于 Allow 规则**，所以只加放行是不起作用的。

手动检查：

若「公用配置文件」是「启用」且策略为 `BlockInbound`，手机发来的 TCP 握手会被直接丢掉（广播包也一样）。最省事的是把当前 Wi-Fi 改成「专用网络」（设置 → 网络和 Internet → WLAN → 属性 → 网络配置文件：专用），专用配置文件的防火墙通常是关的；要用命令放行则需要管理员权限：

```
netsh advfirewall firewall add rule name="Pixelorama LAN Sync" dir=in action=allow protocol=TCP localport=45990-45997
netsh advfirewall firewall add rule name="Pixelorama LAN Sync UDP" dir=in action=allow protocol=UDP localport=45999
```

如果上面命令里 `LocalFirewallRules` 显示 `N/A (仅 GPO 存储)`，说明规则由组策略下发，本机加的规则可能被覆盖——那就只能改网络配置文件或让管理员改组策略。

## 限制与注意

- **没有单文件大小上限**：文件按 256 KB 分块读写，内存里同时只有一块，几百 MB 的工程文件也能过；哈希也是边读边算，不会把文件整个读进来。单次每个文件夹最多 4000 个文件。
- 忽略 `.godot`、`.import`、`.git` 以及所有以 `.` 开头的项。
- 同一台机器上跑两个实例时，发现端口只能被一个进程绑定，另一个会退化成「只能被对方发现」——此时用「按地址连接」填 `127.0.0.1:45990`。
- Android 需要 `INTERNET` 权限（本项目导出预设已开启）。部分路由器会隔离客户端（AP isolation），那样广播到不了，需改用手填地址。
- 冲突规则是「修改时间较新者胜」，同一秒内改动可能被对方覆盖；建议两侧不要同时改同一个文件。
